# 使用场景

## 场景一：一个微信管几家店

**情况**：店主账号只能登自己那家店，连锁或者代购的几家店要分开管。

**做法**：

1. 用「经营账本」拿店主 SID，建店 A；
2. 用「经营码店员助手」切到另一家店，拿店员 SID，建店 B；
3. 之后在店铺下拉里切换，各自拉取商品、排序、改标签。

每家店各存各的 SID，互不影响。

## 场景二：只改排序/标签，不碰库存

**问题**：手机上调顺序、改标签太慢，又怕误改库存和价格。

**做法**：这个工具只动小程序里的排序（`sortgoods`）和商品编辑（`goods/edit`），
只改顺序、标签、分类，**不会改库存数字和价格**。

适合：店长整理货架时用，不容易误改。

## 场景三：新品上架后统一打「新品」标签

**做法**：

1. 拉取商品；
2. 切到对应分类；
3. 多选新上的商品（按住 Ctrl 点选）；
4. 点「设置标签」→「新品」；
5. 保存到小程序。

## 场景四：活动期间把爆款置顶

**做法**：

1. 选中爆款，用「置顶」或直接拖到第一行；
2. 保存；
3. 活动结束后再拖回原位（保存前有备份可查）。

也可以按「销量从高到低」或「库存从多到少」一键重排。

## 场景五：店员代管门店，但不给店主账号

**问题**：店员只被授权管理商品，没有店主账号。

**做法**：店员登录「经营码店员助手」，拿 `auth_type=4` 的 SID。
工具会自动认出来，并带上 `mch_id / shop_id`，拉取、排序、改标签都正常。

## 场景六：新店先把顺序排好

**做法**：

1. 拉取商品；
2. 每个分类先点「应用策略」→「销量从高到低」或「名称」；
3. 再手动微调前几行；
4. 逐分类保存。

## 场景七：商品太多，看不清图

**做法**：Ctrl+滚轮放大到 80–120px，图片和行高一起变大，方便核对商品；
核对完再缩小回 36px，一屏看更多。

## 不适合的场景

- 需要新建商品 → 本工具只管理已有商品的顺序、标签和分类；
- 需要改价格/库存 → 请用小程序后台或店员助手操作。
