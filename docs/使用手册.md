# 使用手册

> 本工具由 AI 制作，纯个人自用；微信下单助手没有官方 API，
> 通过抓取小程序 SID、调用其内部接口来实现在电脑上管理商品。

## 1. 安装与启动

### 安装版

1. 解压 `微信下单助手小程序管理_v1.0.0_安装包.zip`；
2. 双击 `微信下单助手小程序管理_安装包_v1.0.0.exe`；
3. 点「安装」，装到 `%LOCALAPPDATA%\微信下单助手小程序管理`，不需要管理员权限；
4. 从桌面或开始菜单打开「微信下单助手小程序管理」。

安装器默认**不会**自动启动程序。

### 源码运行

```bat
pip install pillow
python src\gui.py
```

`src\config.json` 中 `app_mode` 为 `shop` 时只显示「排序标签」页。

## 2. 抓取 SID

SID 是微信小程序的登录态，分两种：

| 来源 | auth_type | 说明 |
| --- | --- | --- |
| 经营账本 → 商品管理 | 3 | 店主账号 |
| 经营码店员助手 → 商品页 | 4 | 店员账号，带 `mch_id / shop_id` |

步骤：

1. 点右上角 **「抓取 SID」**（按钮会变成「停止抓取」）；
2. 电脑微信打开对应小程序，进入 **商品页** 并刷新一下列表；
3. 抓到后：
   - 店主：弹「抓取成功」，SID 自动填入并复制到剪贴板；
   - 店员：弹「抓到店员 SID」，命名后保存为新店铺（或更新已有店铺）；
4. 顶部状态会变成绿色：`● SID 有效 · 店员 · 尾号 xxxxxx`。

> 店员 SID 必须同时带 `mch_id` 和 `shop_id` 才会被接受；缺一个会继续等待下一条请求。

### SID 状态

- 打开程序 1.5 秒后自动探测当前店铺；
- 切换店铺后 0.4 秒自动探测；
- 每 2 分钟后台复检一次；
- 点击顶部那行状态可以立即手动复检；
- 失效变红：`● SID 未通过检测`，重新抓取即可。

## 3. 店铺管理

- **切换**：右上角「店铺」下拉；
- **新增**：点 **＋**，填名称和 SID；
- **修改**：点「设置」，可改名、改 SID、删除店铺（至少保留一个）；
- 每个店铺独立保存 SID 和店员参数，切换时自动清空上一个店的数据，避免串店；
- 程序会记住上次选中的店铺。

## 4. 拉取商品

1. 切到 **「排序标签」** 页；
2. 点 **「拉取商品」**；
3. 按钮变「拉取中…」，底部显示进度：
   `3/16 乳品烘焙 · 第 2 页 · 已拉取 120 个`；
4. 拉完后左侧出现分类下拉和商品列表（含缩略图）。

商品多时（1000+）大约需要几十秒，期间不要重复点击。

## 5. 排序

- **拖动**：按住任意一行上下拖，松手后顺序生效；
- **按钮**：上移 / 下移 / 置顶 / 置底；
- **策略**：名称、库存从多到少、销量从高到低、价格从低到高、条码，点「应用策略」；
- 调整后点 **「保存到小程序」**，会把当前分类的**完整顺序**提交给小程序。

> 保存会覆盖该分类在小程序里的顺序，以页面显示的顺序为准。
> 保存前自动备份到 `data\backup\sort_*.json`。

**置顶/置底不会带着视图跳走**：只移动那一行并重排序号，当前滚动位置保持不变。

## 5.1 分类管理

- **新建分类**：点工具栏「新建分类」，输入名称即可；
- **批量设置分类**：多选商品 → 点「设置分类」→ 选择目标分类；
- 移动完成会把商品从当前分类移除，并逐个写回小程序（写前备份到 `data\backup\category_*.json`）；
- 失败会列出商品名和原因。

## 6. 标签

标签共四档：**无 / 招牌 / 新品 / 热销**。

1. 选中一行或多行；
2. 点「设置标签」，或直接双击一行；
3. 选择标签；
4. 点「保存到小程序」写回。

## 7. 缩放

在商品列表里按住 **Ctrl 滚动滚轮**：

- 行高和缩略图一起放大/缩小；
- 范围约 30–160px，默认 44px 行高 / 36px 图；
- 停 90ms 后统一应用，连续滚动不卡顿。

## 8. 常见问题

**抓不到 SID**

- 先看状态：`已看到 N 条微信请求`；
- 0 条：确认电脑微信「设置 → 通用 → 代理」使用系统代理；或换到商品页刷新；
- N 条但没弹窗：把 `%LOCALAPPDATA%\微信下单助手小程序管理\data\capture\requests.log` 发出来。

**SID 显示无效**

- 店员 SID 会随登录态轮换，重新抓一次；
- 确认在正确的店铺上操作（顶部会显示店铺名）。

**拉取很慢**

- 商品 1000+ 时属正常，底部有实时进度；
- 网络差时每页会重试，耐心等进度条走完。

**保存后顺序没变**

- 小程序有缓存，退出重进商品页查看；
- 确认保存时弹出的结果提示为「排序已保存」。

**图片不显示**

- 首次拉取后缩略图按需下载，稍等；
- 没有图片的商品显示灰色占位图。
