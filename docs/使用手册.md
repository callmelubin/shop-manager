# 使用手册

> 这个工具是我用 AI 做的，自己用。微信下单助手没有开放官方接口，
> 所以只能先拿到小程序的登录凭证（SID），再按小程序自己的方式去改。

## 1. 安装与打开

### 安装版

1. 把压缩包解压到桌面或下载目录；
2. 双击 `微信下单助手小程序管理_安装包_v1.0.0.exe`；
3. 点「安装」，会装到 `%LOCALAPPDATA%\微信下单助手小程序管理`，不用管理员权限；
4. 装完从桌面或开始菜单打开「微信下单助手小程序管理」。

装完不会自己弹出来，需要你手动打开。

### 用源码运行

```bat
pip install pillow
python src\gui.py
```

`src\config.json` 里的 `app_mode` 是 `shop` 时，只显示「排序标签」这一页。

## 2. 拿 SID

SID 就是小程序的登录凭证，有两种：

| 从哪进 | auth_type | 说明 |
| --- | --- | --- |
| 经营账本 → 商品管理 | 3 | 店主账号 |
| 经营码店员助手 → 商品页 | 4 | 店员账号，会带上 `mch_id / shop_id` |

步骤：

1. 点右上角 **「抓取 SID」**（按钮会变成「停止抓取」）；
2. 在电脑微信里打开对应的小程序，进 **商品页**，刷新一下列表；
3. 拿到以后：
   - 店主：会弹「抓取成功」，SID 自动填好，也复制到剪贴板了；
   - 店员：会弹「抓到店员 SID」，起个店铺名保存就行（已有店铺会直接更新）；
4. 顶部会变绿：`● SID 有效 · 店员 · 尾号 xxxxxx`。

> 店员 SID 得同时带上 `mch_id` 和 `shop_id` 才算数，少一个就会继续等下一条请求。

### 怎么看 SID 还有没有效

- 打开程序 1.5 秒后，自动查一次当前店铺；
- 切换店铺后，0.4 秒自动查一次；
- 之后每隔 2 分钟在后台再查一次；
- 点一下顶部那行状态，可以马上再查；
- 过期会变红：`● SID 未通过检测`，重新抓一次就好。

## 3. 管店铺

- **切换**：右上角「店铺」下拉；
- **新增**：点 **＋**，填名字和 SID；
- **修改**：点「设置」，能改名、改 SID、删店铺（至少要留一个）；
- 每个店各存各的 SID，切店时会把上一个店的数据清掉，免得串店；
- 程序会记住你上次选的是哪家店。

## 4. 拉取商品

1. 切到 **「排序标签」** 页；
2. 点 **「拉取商品」**；
3. 按钮会变成「拉取中…」，底部有进度：
   `3/16 乳品烘焙 · 第 2 页 · 已拉取 120 个`；
4. 拉完左边会出现分类下拉和商品列表，带缩略图。

商品多的时候（1000 多个）要几十秒，这期间别再点。

## 5. 调顺序

- **拖动**：按住一行上下拖，松手就生效；
- **按钮**：上移 / 下移 / 置顶 / 置底；
- **一键排**：名称、库存从多到少、销量从高到低、价格从低到高、条码，选好点「应用策略」；
- 调完点 **「保存到小程序」**，会把当前这个分类的顺序整个保存过去。

> 保存会把小程序里这个分类的顺序换成你现在看到的顺序。
> 保存前会自动备份到 `data\backup\sort_*.json`。

**置顶、置底不会把页面带着跳走**：只挪那一行、重排一下序号，你看的位置不动。

## 6. 管分类

- **新建分类**：点「新建分类」，输个名字就行；
- **批量改分类**：多选商品 → 点「设置分类」→ 选要挪到哪个分类；
- 挪完会从当前分类里拿掉，并一个个保存到小程序（保存前备份到 `data\backup\category_*.json`）；
- 有失败会列出商品名和原因。

## 7. 打标签

标签就四种：**无 / 招牌 / 新品 / 热销**。

1. 选中一行，或者多选几行；
2. 点「设置标签」，也可以直接双击一行；
3. 选标签；
4. 点「保存到小程序」。

## 8. 放大缩小

在商品列表里按住 **Ctrl 滚轮**：

- 行高和缩略图一起变大变小；
- 大概 30–160px，默认行高 44px、图 36px；
- 停下来 90 毫秒才真正调整，连续滚不会卡。

## 9. 遇到问题

**抓不到 SID**

- 先看状态栏有没有「已看到 N 条微信请求」；
- 是 0 条：看看电脑微信「设置 → 通用 → 代理」是不是用了系统代理，或者换个商品页刷新；
- 有 N 条但没弹窗：把 `%LOCALAPPDATA%\微信下单助手小程序管理\data\capture\requests.log` 发出来。

**SID 说无效**

- 店员 SID 会跟着登录状态变，重新抓一次；
- 确认是在正确的店铺上操作（顶部会显示店铺名）。

**拉取很慢**

- 1000 多个商品本来就慢，底部有实时进度；
- 网络不好时每页会重试，等进度条走完。

**保存完顺序没变**

- 小程序有缓存，退出商品页再进来看；
- 看看保存后有没有弹「排序已保存」。

**图片不显示**

- 缩略图是拉取后按需下载的，等一会儿；
- 没图的商品会显示灰色占位图。
